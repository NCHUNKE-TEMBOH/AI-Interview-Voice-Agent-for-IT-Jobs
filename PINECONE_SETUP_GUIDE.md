## What is Pinecone?

Pinecone is a vector database optimized for machine learning applications. It allows you to:
- Store high-dimensional vectors (embeddings)
- Perform fast similarity searches
- Scale automatically without managing infrastructure
- Integrate easily with AI/ML applications

In our RAG system, Pinecone will store document embeddings generated by Google Gemini, enabling fast retrieval of relevant content for AI responses.

## Creating a Pinecone Account

### Step 1: Sign Up
1. Go to [https://www.pinecone.io/](https://www.pinecone.io/)
2. Click the **"Start Free"** or **"Sign Up"** button

1. Check your email for a verification link (if signing up with email)
2. Click the verification link to activate your account
3. Complete any additional profile information requested

### Step 3: Choose Your Plan
Pinecone offers several plans:
- **Starter (Free)**: 
  - 1 Project
  - 1 Index
  - Up to 100,000 vectors
  - 5GB storage
  - Perfect for development and testing
  
- **Standard ($70/month)**:
  - Unlimited projects
  - Unlimited indexes
  - Pay-as-you-go pricing
  - Recommended for production

For development, the **Starter (Free)** plan is sufficient.

## Creating an Index

An index is where your vectors will be stored. For our RAG system, we'll create an index optimized for Gemini embeddings.

### Step 1: Navigate to Indexes
1. In your project dashboard, click on **"Indexes"** in the left sidebar
2. Click **"Create Index"**

### Step 2: Configure Your Index
Fill in the following details:

#### Basic Settings
- **Index Name**: `ai-interview-docs` (must be unique)
- **Dimension**: `768` (This is the dimension of Gemini text-embedding-004 model)
- **Metric**: `cosine` (Recommended for semantic similarity)
  - Alternative options: `euclidean`, `dotproduct`

#### Advanced Settings
- **Pod Type**: `p1` (Recommended for production)
  - `s1` - Starter pod (free tier)
  - `p1` - Performance optimized
  - `p2` - Performance optimized with more storage

- **Pod Size**: `1x1` (Start small, scale as needed)
  - Options: `1x1`, `1x2`, `2x1`, `2x2`, etc.

- **Replicas**: `1` (Start with 1, increase for high availability)
- **Shards**: `1` (Increase for larger datasets)

#### Serverless Option (Alternative)
For the free tier, you can use **Serverless**:
- **Cloud Provider**: `AWS` (or `GCP`, `Azure`)
- **Region**: `us-east-1` (or your preferred region)
- **Environment**: `production`

### Step 3: Create the Index
1. Review your settings
2. Click **"Create Index"**
3. Wait for the index to be provisioned (usually 1-2 minutes)
4. You'll see a green checkmark when ready

### Step 4: Note Your Index Details
After creation, note down:
- **Index Name**: `ai-interview-docs`
- **Index Host**: `https://ai-interview-docs-abc123.svc.pinecone.io` (auto-generated)
- **Dimension**: `768`
- **Metric**: `cosine`

## Configuring Environment Variables

Add the following variables to your `.env` file:

```env
# Pinecone Configuration
PINECONE_API_KEY=your_pinecone_api_key_here
PINECONE_ENVIRONMENT=production
PINECONE_INDEX_NAME=ai-interview-docs
PINECONE_PROJECT_ID=your_project_id_here
```

### Where to Find Each Value

| Variable | Where to Find It |
|-----------|------------------|
| `PINECONE_API_KEY` | API Keys section in Pinecone Console |
| `PINECONE_ENVIRONMENT` | Usually `production` or `us-east-1-gcp` |
| `PINECONE_INDEX_NAME` | The name you gave your index |
| `PINECONE_PROJECT_ID` | In the URL when viewing your project: `app.pinecone.io/projects/YOUR_PROJECT_ID` |

## Testing Your Setup

### Step 1: Install Pinecone Client

```bash
npm install @pinecone-database/pinecone
```

### Step 2: Create a Test Script

Create a file `test-pinecone.js`:

```javascript
import { Pinecone } from '@pinecone-database/pinecone';

async function testPinecone() {
  try {
    // Initialize Pinecone
    const pinecone = new Pinecone({
      apiKey: process.env.PINECONE_API_KEY,
    });

    // List indexes to verify connection
    const indexes = await pinecone.listIndexes();
    console.log('✅ Connected to Pinecone!');
    console.log('Available indexes:', indexes);

    // Get the index
    const index = pinecone.index(process.env.PINECONE_INDEX_NAME);
    console.log('✅ Index accessed:', process.env.PINECONE_INDEX_NAME);

    // Test stats
    const stats = await index.describeIndexStats();
    console.log('✅ Index stats:', stats);

  } catch (error) {
    console.error('❌ Error connecting to Pinecone:', error);
  }
}

testPinecone();
```

### Step 3: Run the Test

```bash
node test-pinecone.js
```

Expected output:
```
✅ Connected to Pinecone!
Available indexes: [{ name: 'ai-interview-docs', ... }]
✅ Index accessed: ai-interview-docs
✅ Index stats: { totalVectorCount: 0, dimension: 768 }
```

## Understanding Vector Dimensions

Different embedding models produce different vector dimensions:

| Model | Dimensions | Use Case |
|--------|-------------|-----------|
| `text-embedding-004` (Gemini) | 768 | Our RAG system |
| `text-embedding-ada-002` (OpenAI) | 1536 | Alternative |
| `all-MiniLM-L6-v2` (Sentence Transformers) | 384 | Lightweight |

**Important**: Your Pinecone index dimension MUST match your embedding model's dimension.

## Best Practices

### Security
- Never commit API keys to Git
- Use environment variables in all environments
- Rotate API keys periodically
- Use separate keys for development and production

### Performance
- Start with the free tier for testing
- Monitor your vector count and storage usage
- Use appropriate pod sizes based on your data
- Consider serverless for variable workloads

### Cost Management
- Free tier: 1 index, 100K vectors, 5GB storage
- Monitor usage in the Pinecone Console
- Delete unused indexes to save costs
- Set up billing alerts

## Troubleshooting

### Common Issues

#### Issue: "Invalid API Key"
**Solution**: 
- Verify your API key is correct
- Check for extra spaces or characters
- Ensure the key hasn't been revoked

#### Issue: "Index not found"
**Solution**:
- Verify the index name matches exactly (case-sensitive)
- Check you're in the correct project
- Ensure the index has finished provisioning

#### Issue: "Dimension mismatch"
**Solution**:
- Verify your embedding model's output dimension
- Recreate the index with the correct dimension
- Check Gemini embedding model version

#### Issue: "Rate limit exceeded"
**Solution**:
- Wait a few minutes before retrying
- Upgrade your plan if needed
- Implement retry logic in your code
